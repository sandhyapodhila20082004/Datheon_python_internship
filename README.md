Datheon Python Programming Internship

This repository contains Python projects completed as part of the Datheon Python Programming Internship.

Task 1: Hangman Game

A terminal-based word guessing game where the user guesses a hidden word within six incorrect attempts.

Features

- Random word selection
- ASCII Hangman graphics
- Tracks guessed letters
- Prevents duplicate guesses
- Victory and defeat screens

Task 2: Automated File Organizer

A Python utility that automatically organizes files into folders based on their extensions.

Features

- Organizes documents, images, videos, archives, and code files
- Automatically creates category folders
- Moves files using Python libraries
- Handles duplicate filenames
- Displays an execution summary

Technologies Used

- Python 3
- Random
- OS
- Shutil
- Pathlib


How to Run

Download or clone this repository.

Run the following commands in the terminal:

python hangman.py

For the File Organizer, enter the directory path you want to organize.

Note: Test the File Organizer using a separate test folder before using it on important files.
